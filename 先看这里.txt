衣账 · 四店工资助手 v0.4

一、打开方式
双击“工资助手.html”，用新版 Chrome 或 Edge 打开。不用安装，不用输入代码。
这几个文件必须放在一起：工资助手.html、app.js、core.js、excel.js、style.css。
已经打开旧页面的，先刷新；看不到新按钮时按 Ctrl+F5。
桌面的“工资助手”快捷方式仍然有效，不用重新创建。

本版界面更新：
顶部一条汇总栏：计薪人数、应发合计、扣款合计、软件实发合计，随月份和店铺筛选变化。
工资明细更紧凑；状态用“小圆点 + 文字”显示，例如“● 待核实”。
手机窄屏会改为逐人卡片；原有工资算法及数据保存方式不变。

二、导入工资单
1. 软件里已有数据的，先到“店铺与备份”下载 JSON 完整备份。
2. 在正式空间点击“导入 Excel”，选择公司的 .xlsx 工资单。
   不要在顶部带黄色“演示空间”提示的页面导入真实工资。
3. 先核对原表月份。软件按表内日期识别，不会直接改成当前月份。
4. 核对店铺。没有明确归属的先选“待确认归属”；确定属于某店的可以直接选择。
5. 核对员工匹配。编号重复不代表同一个人，同名员工也需人工确认。
6. 检查软件计算与原表实发。空白实发不是 0 元，存在差额也不会自动补齐。
7. 点击“确认导入所选记录”。重复文件同一行会被拦截，已有工资不会被覆盖。
8. 逐人“编辑工资”，处理归属店铺、缺项和差异。
9. 向公司核实后，才勾选“已向公司核实”并填写说明。不能为了消除提示而随便补数。
10. 全部待核实事项处理后，再审核锁账、导出和备份。

三、支持的项目
应发：基本工资、饭贴、提成、奖金、房贴、社保应发项、其他补贴、其他补发、退还押金。
扣款：请假、迟到、买衣服、预支工资抵扣、历史押金扣款、其他扣款、个人社保公积金、个税。
请假天数单独记录，不根据天数自动猜扣款。
社保出现在应发区域时不能直接当成个人社保扣款，需要确认实际口径。
明确的退押金、扣押金、提成及补发备注可单列金额；有歧义的只保留和提示。
对应数字栏已经有金额的，不重复加算。
押金项目只用于如实核对历史数据，是否可以扣收由公司核实，不设为自动扣款。

提成小助手（方便不会电脑的老板）：
打开某位员工的“编辑工资”，弹窗上方有“提成小助手”。
先选方式：按比例（填业绩基数和百分比）、固定金额、每件提成（填件数和每件金额），
或选“自定义算式”直接写，例如 (50000－2000)×3%＋300，支持数字、＋－×÷、％、括号。
下面的“计算结果”会实时显示；确认无误后点“填入提成”，结果就写进“提成”栏。
填进去只是草稿，还要点“保存本月工资”才会生效；算错会给出红色提示，不会静默算成 0。

四、核对与历史
员工档案每人后面都有月度备注框，上方“备注月份”独立选择想记录的月份。
例如选择 2026 年 11 月，写完后点击该员工的“保存备注”；切换到 12 月会显示另一份备注，不会覆盖 11 月。
备注最多 1000 字；切换月份会保留当前页面里未保存的草稿，但关闭或刷新前请先保存。
这类备注仅内部使用，不进入个人工资条或工资 Excel/CSV；已保存的备注会进入 JSON 完整备份。
备注不改变工资金额，不自动清除工资核实状态；未生成工资或工资已锁账时也可以记录。
清空已有内容再保存会要求确认，只清空当前员工当前月份的备注。
软件实发与原表实发分别保存，修改计算项目不会改掉原表实发。
可查看源文件名、工作表、行号及关键单元格，便于回查。
员工档案变更不会改动历史工资；当月归属店铺可在工资编辑里独立调整。
员工档案每行有“删除员工”：点击后确认，再输入“删除员工”才会删除；取消或输错不会删除。
删除后员工不再出现在档案列表，也不再自动生成工资；已有各月工资、锁账及工资条全部保留。
这是保留历史关联的逻辑删除，JSON 备份中仍有已删除档案，不是彻底清除个人信息。
删除没有直接撤销按钮，操作前建议先下载完整备份；仅离职建议编辑档案改为“停用 / 离职”。
导入时新建档案的“工资启用月份”不是已核实的入职日期，在职状态也需人工确认。
每月新生成工资只带入默认底薪，不会自动重复上月押金扣退、补发或提成。
旧版数据和旧 JSON 备份可以兼容读取，新增工资项目补 0，不改变原金额。

五、导出和备份
“导出 Excel”生成真正的 .xlsx，包含“工资汇总”和“工资条”两张表。
“导出 CSV”也可用 Excel/WPS 打开。两种导出都只包含当前筛选结果。
个人工资条只含个人信息，可下载或打印/另存 PDF。
未核实的记录会明确标注，不代表可以直接发薪。
完整恢复使用 JSON 备份，Excel/CSV 不等于完整系统备份。
文件保存窗口请选择 D 盘；浏览器直接下载的，请先开启“每次下载前询问保存位置”。

清空全部数据：
在“店铺与备份”页面最下方有“清空全部本机数据”。点击后确认，再输入“清空数据”才会执行。
它会同时删除正式空间和演示空间的员工、工资、锁账、操作记录和月度备注，网页文件不受影响。
此操作不可撤销，也无法刷新找回；执行前请务必先点“下载完整备份”保存到 D 盘。

六、数据安全与使用边界
原始 Excel 只读，工资文件不上传，不执行宏、公式或外部链接。
自动化测试全部使用虚构员工和金额，不把真实工资写入测试缓存或演示数据。
数据保存在当前电脑、当前浏览器的本地存储，没有登录权限或加密。
同一浏览器的使用者可能看到工资，备份及导出也是明文，不可公开分享。
换浏览器、移动网页、清理数据或使用隐私模式，可能无法读取原数据。
请每次结算后下载完整 JSON 备份，存到受保护的文件夹。
锁账只防误改，不等于已经发薪；解锁需填写原因。
自动提成、考勤折算、个税计算、淘宝对接、多人权限等暂未实现。
发真实工资前，必须由公司核对确认，通用检查项见“工资核对清单.txt”。
