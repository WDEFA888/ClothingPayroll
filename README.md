# 衣账 · 四店工资助手 v0.4

单机浏览器工资原型，面向两家实体店、两家淘宝店。双击 `工资助手.html`，使用新版 Chrome / Edge 打开；无需服务器、安装依赖或联网。中文说明见 `先看这里.txt`，通用核对清单见 `工资核对清单.txt`。

## 界面（v0.4）

- 去掉英文装饰小标题、姓名头像、胶囊徽章和装饰插画，改为中性灰边框、深绿主色、6px 圆角；状态用“小圆点 + 文字”表达。
- 汇总改为一条四格数字栏（人数、应发、扣款、实发），随月份、店铺和姓名/岗位筛选更新；实发格浅绿强调。
- 表格更紧凑：姓名与“岗位 · 店铺”两行显示，金额等宽右对齐，行高压缩。
- 图标改用 [Tabler Icons](https://github.com/tabler/tabler-icons)（MIT），内联为 SVG，不加载外部资源；许可证见 `icons/LICENSE-tabler.txt`。
- 手机工资表与员工表仍为逐人卡片；平板使用窄侧栏。
- 不改变工资算法、存储键、备份格式或正式/演示空间隔离方式。

## 工资功能

- 四家实际店铺与“待确认归属”临时分类；不将无法识别的原表标题擅自映射到某店。
- 跨店员工、默认底薪、工资启用月份、在职/停用档案；启用月份不等于已核实的入职日期。
- 员工档案可删除，需确认并输入“删除员工”。删除后从档案列表和导入匹配中隐藏，不再自动生成工资；已有工资、锁账记录和工资条全部保留。采用逻辑删除，关联档案仍保存在本地数据与 JSON 备份中，不是个人信息彻底清除；仅离职建议改为停用。
- 按月生成独立快照、补充员工，不覆盖已填金额；只默认带入底薪，不重复上月押金或补发。
- 员工档案每行提供月度备注框，上方单独选择备注月份。每人每月最多 1000 字，点击“保存备注”才写入本机；切换月份保留当前页面的未保存草稿，关闭或刷新前会提示。清空已有备注需确认。
- 月度备注与工资备注分开：不影响金额、核实状态或锁账；未生成工资、工资已锁账时也可备注。不进入工资 CSV、Excel 或个人工资条，JSON 完整备份包含已保存备注；删除员工保留历史备注关联。
- 9 类应发：基本工资、饭贴、提成、奖金、房贴、社保应发项、其他补贴、补发、退押金。
- 8 类扣款：请假、迟到、衣服、预支、历史押金扣款、其他扣款、个人社保公积金、个税。
- 金额使用整数分，天数使用百分之一天；请假天数只记录，不推导扣款公式。
- 工资编辑里带“提成小助手”：按比例（基数×百分比）、固定金额、每件提成三种方式，或直接写自定义算式（如 `(50000－2000)×3%＋300`），算出结果后点“填入提成”才写入提成栏，不自动改金额。算式仅支持数字与 ＋－×÷％括号，本地解析、不执行脚本，结果精确到分。
- 按姓名/岗位检索、归属店铺筛选、当前筛选合计；个人工资条下载与打印。
- 锁账/说明原因解锁；最近 500 条本地操作日志；JSON 完整备份与校验恢复。
- 完整备份用密码加密（AES-GCM + PBKDF2，200000 次迭代），防止备份文件泄露工资；旧版明文备份仍可恢复并提示重新加密。
- 在“店铺与备份”可一键清空正式空间和演示空间的全部本机数据（员工、工资、锁账、操作记录、月度备注），需确认并输入“清空数据”；操作不可撤销，应先下载完整备份。

## 安全边界

- 页面 CSP 禁止外部脚本、样式、图片与网络连接；应用代码不发起任何网络请求。
- 所有用户可控文本（姓名、岗位、店名、备注、原表内容）写入页面前统一转义；浏览器测试用恶意 `<img onerror>`、`<svg onload>` 验证不执行。
- 备份校验拒绝 `__proto__`、`constructor`、`prototype` 字段；恢复时只复制已知顶层字段，避免原型污染。
- XLSX 读取拒绝路径穿越、重复条目、加密标记、DTD/实体声明、ZIP64、多卷、异常声明体积与 CRC 不符；限制 20MB 文件、32MB 展开、8MB 单条目、1000 条记录。
- 桌面版关闭 `nodeIntegration`、启用 `contextIsolation` 与 `sandbox`，禁用 webview；只允许“演示空间”一个白名单新窗口，阻止跳转到外部网址，拒绝所有权限请求；保存接口校验调用来源、文件名和 50MB 上限。
- 桌面版每次保存都会在 `userData` 下另存一份 `工资数据.json` 镜像；启动时若本地缓存为空会自动恢复，清空数据时同步删除镜像，降低缓存被清或损坏导致的数据丢失风险。
- 已知限制：安装包未做代码签名，Windows SmartScreen 会提示；数据未加密，依赖本机账户安全；没有自动更新，需手动安装新版。

## 本地 Excel

`excel.js` 是无第三方依赖的 XLSX 读写模块。

- 支持店家分块工资条布局和本工具导出的汇总表；逐块识别表头，而非固定列位置对应固定项目。
- ZIP 中央目录、CRC、路径、大小、压缩方式及 XML 校验；限制文件 20MB、展开 32MB、单条目 8MB，一次最多 1000 条工资。
- 使用浏览器 `DecompressionStream('deflate-raw')` 读取压缩内容。不要直接修改 `.xls` 后缀；不支持 `.xls`、`.xlsm`、加密或 ZIP64 工作簿。
- 不执行公式、宏或外部链接；公式只取保存的缓存值并产生核对提示。拒绝 XML DTD/实体声明。
- 读取 Excel 日期和文本月份；不默认用当前月份替代原表月份。改变月份需要明确确认，不允许将多个源月份混为一个月。
- 保留源文件名、SHA-256、工作表、原表行号/编号、关键单元格与原表实发。重复编号不作为员工身份。
- 同名档案在预览中明确显示匹配选择；同文件同一行不能重复导入。同员工同月已有工资则整批失败，不静默覆盖。
- 仅对明确的退押金、扣押金、提成与加法补发备注列项；数字栏已有对应金额时不重复加算。其他备注保留并要求核实。
- 原表实发空白保存为 `null`，而不是零；软件实发独立计算，绝不为了对齐而自动添加差额。
- 店铺未分配不能锁账。缺实发、金额差异、请假缺扣款及来源警告需人工核实说明；修改工资内容后清除旧确认。
- 导出真正的 `.xlsx`（工资汇总、工资条两表）或 CSV，包含当前筛选记录。所有文本使用 inline string，不变成公式。

## 兼容与数据边界

继续使用 `yizhang-payroll-v1` 本地键和独立 `-demo` 演示键，避免旧数据丢失。数据结构升级至 `version: 2`，v1 读取时克隆升级，新增项目补零，不改变原金额；首次明确保存前不自动写回。v1 JSON 备份同样可恢复。

这不是生产级工资平台：无登录权限、加密存储、服务端、多用户审批、自动提成、考勤折算、个税计算、银行发薪或淘宝对接。工资表的字段和备注不能证明完整计算规则。应发社保与个人扣款必须区分；历史押金项目只是记录，性质及合规性由公司核实。

localStorage 不保证长期保存；移动文件、换浏览器、清理存储或隐私模式可能失去对原数据的访问。必须下载 JSON 备份到安全文件夹。备份恢复为明确确认后的全量替换，不等于合规审批链；日志也不是不可篡改审计。多标签页冲突检测用于降低误覆盖风险，不等同事务数据库。

真实工资由用户在正式页面选择文件、预览并确认后才写入本地空间。不将真实工资文件打包进项目、源代码、演示或自动化测试。不要公开分享明文备份或导出文件。

## 文件

- `工资助手.html`、`style.css`：入口、响应式界面、工资条打印样式。
- `core.js`：计算、校验、兼容升级、导入事务、防重复、核实、锁账、CSV。
- `excel.js`：本地 ZIP/XLSX 读写、模板识别、来源保存。
- `app.js`：界面、持久化、预览及导入导出。
- `tests/core.test.js`：31 项 Node 内建测试，含提成算式、员工删除、月度备注隔离、历史保留、备份兼容和原型污染防护。
- `tests/browser.test.js`：Node 24 WebSocket / Chrome CDP 界面回归。
- `tests/make-fixture.js`：从零生成虚构工资文件，不读取真实工资。
- `tests/ui-checks.js`：真实浏览器内计算正文、表单值与占位文字的颜色对比度；排除禁用控件和装饰内容。
- `desktop/`：Electron 桌面版工程（`main.js`、`preload.js`、`package.json`、`build/icon.ico` 与复制的应用文件）。
- `versions/`：升级前的源文件副本，不包含浏览器工资数据库。

## 桌面安装包

`desktop/` 用 Electron 把同一个网页应用打包成 Windows 桌面程序，老板只需下载一个安装包、装完即可用，不需要浏览器或安装其他环境。

- 安装包输出在 `desktop/dist/衣账工资助手-安装包-0.4.0.exe`，安装后可改目录，自动创建桌面和开始菜单快捷方式。
- `desktop/dist/win-unpacked/` 是解压即用的绿色版文件夹，双击 `衣账工资助手.exe` 运行。
- 桌面版仍用同样的 `工资助手.html` 数据逻辑；导出/备份通过 `preload.js` 的 `window.desktop.saveFile` 走系统“另存为”对话框。网页版继续用浏览器下载方式。
- 本机打包步骤（全部落在 D 盘）：
  ```sh
  NODE='/d/Tools/dsh-home/dsh-runtimes/dsh-primary-runtime/dependencies/node/bin/node.exe'
  NPM="$NODE /d/Tools/npm/bin/npm-cli.js"
  cd /d/Projects/ClothingPayroll/desktop
  ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ \
  ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/ \
  "$NODE" node_modules/electron-builder/cli.js --win nsis
  ```
- 安装包未做代码签名，Windows 首次运行会显示 SmartScreen 提示，需点“更多信息 → 仍要运行”；详见 `desktop/dist/安装说明.txt`。
- `tests/electron-smoke.js` 用 CDP 验证桌面版（开发版与打包版）能打开、`window.desktop.saveFile` 存在、localStorage 可读写、界面无渲染错误。

## 本机验证

使用已有 D 盘 Node，无需 npm 依赖：

```sh
NODE='/d/Tools/dsh-home/dsh-runtimes/dsh-primary-runtime/dependencies/node/bin/node.exe'
"$NODE" --test 'D:/Projects/ClothingPayroll/tests/core.test.js'
"$NODE" 'D:/Projects/ClothingPayroll/tests/browser.test.js' --excel
```

浏览器默认使用本机 Chrome，可通过 `PAYROLL_BROWSER` 指定 Chromium 可执行文件。测试资料、虚构下载和截图全部保存在 D 盘 `tests/browser-artifacts/run-时间戳/` 独立目录，不读写正常浏览器的数据。

`--excel` 用 23 位虚构员工测试重复编号、两种日期、不同块表头、社保方向、备注加项、四条空白实发及一条差额；逐行核对全部 17 项金额。虚构 XLSX 用 Python 标准库 ZIP_DEFLATED 压缩，覆盖真实解压路径，不下载依赖。继续验证重复导入拦截、锁账保护、核实说明、修改后清除核实、XLSX 真实下载及重新解析、个人打印样式与 PDF 生成。PDF 查看工具不是必需依赖，打印布局另外用浏览器 print 媒体截图检查。

界面回归还验证筛选汇总、空白月份、导航选中状态，以及 320—1920 像素页面不横向溢出。保存桌面、手机、员工页、空白态、工资编辑和导入弹窗截图；`text-contrast.json` 记录截图状态的文字对比度检查，普通文字要求至少 4.5:1、大字至少 3:1。该检查不等同完整无障碍认证。

如需反复自动启动与验证，可使用 `/run-skill-generator` 固化本机步骤为项目技能。
